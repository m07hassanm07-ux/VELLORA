# توافق ورقة 1.6.0

الهدف هو تبادل ملفات PDF قياسية مع البرامج والمتصفحات، وليس ادعاء التطابق الكامل مع Acrobat Pro أو التوافق الشامل مع كل تطبيق وكل مستند.

## ما نُفّذ

| المجال | الدعم |
|---|---|
| تثبيت البرنامج | مُثبّت Windows x64 للمستخدم الحالي، اختصارات، إلغاء تثبيت، وتسجيل «فتح باستخدام» |
| دمج ملفات PDF | عدة ملفات مع ترتيب مبدئي ثم تنظيم الصفحات داخل المستند |
| تعديل المحتوى | استبدال/حذف عناصر النص والصور المستقلة، وإضافة نصوص عربية وصور مع معاينة؛ راجع EDITING.md للحدود |
| OCR والقراءة | OCR عربي/إنجليزي محلي عبر Tesseract، وبحث وتحديد ونسخ النص |
| جلسات العمل | مشروع `.waraq` وحفظ تلقائي مشفّر محليًا واستعادة الأعطال |
| المراجعة | تمييز وملاحظات وأسهم وأختام كتعليقات PDF قياسية |
| طباعة | نافذة Windows للطباعة، نطاقات صفحات، المحدد والحالي، معاينة، وطباعة دفعية لعدة ملفات، ودعم خيارات النسخ بحسب تعريف الطابعة |
| إنشاء PDF من صور | PNG/JPEG/TIFF/BMP/WebP، مع TIFF متعدد الصفحات |
| Word/Excel/PowerPoint | محول Microsoft Office إن كان البرنامج المناسب مثبتًا؛ أو LibreOffice إن توفر |
| صفحات الويب وHTML | Chrome أو Edge مثبت، بملف تعريف مؤقت لا يستخدم جلسة الحساب الشخصية |
| التكامل مع البرامج الأخرى | فتح ملفات PDF عبر وسيطة سطر الأوامر و«فتح باستخدام»، ووسيط `--print` لفتح نافذة الطباعة |

ملفات الحفظ تستهدف PDF 1.7 على الأقل، وتبقي ترويسة إصدار أعلى عند الحاجة. لا تدعي هذه النسخة اعتماد PDF/A أو PDF/UA. المستندات المشفرة بكلمة مرور قد تختلف طريقة عرضها بين العارضات القديمة.

## أدلة الاختبار المحلية

- 26 اختبارًا آليًا، تشمل التحرير وحذف النص الأصلي وبقاء بقية الصفحة، والعربية والصور والتراجع والتشفير، بالإضافة إلى الطباعة والدمج واختيار الصفحات.
- دمج ثلاثة مستندات تجريبية إلى ملف من 9 صفحات، ثم فتحه عبر pypdf وPDFium وPoppler. أبلغ Poppler أنه PDF 1.7 صالح للقراءة.
- فتح الملف نفسه في Chrome: ظهر العارض بصفحات المستند التسع والنص العربي والصور المصغرة.
- تحويل صفحة HTML تجريبية عبر Chrome إلى PDF، والتحقق من النص وإعادة عرض الناتج.
- تحويل DOCX وXLSX تجريبيين باستخدام Microsoft Office المثبت، والتحقق من نصوصهما وإعادة عرض الصفحات الناتجة.
- لم يتوفر اتصال آلي بواجهة Edge في هذه الجلسة، ولم يجر اختبار عرض الملف في Firefox. لا يُدّعى أنهما اختُبرا.
- لا إرسال لطابعة ورقية أثناء الاختبارات؛ جرى اختبار مسار الطباعة بإخراج PDF. العمل مع تعريفات جميع الطابعات غير مضمون.
- مسار PowerPoint وLibreOffice موجود في الكود لكنه لم يُختبر في هذه الجولة على مستندات فعلية.

نتائج التحويل والمحركات محفوظة في `compatibility-results.json`. نتائج اختبار المُثبّت تسجل في `installer-results.json` عند اكتماله.

اختبارات التحويل والعرض في Chrome المذكورة أعلاه أجريت للإصدار 0.2 في 21 أكتوبر 2026. أعيدت اختبارات الوظائف الآلية والتحرير والمُثبّت للإصدار 0.3 في 22 أكتوبر؛ لا يُدّعى إعادة اختبار جميع محركات Office والمتصفحات بعد كل تعديل.

## من أي برنامج أو متصفح إلى ورّاق

إذا لم يدعم ورّاق صيغة ملف ما مباشرة، استخدم «طباعة» أو «حفظ باسم PDF» في برنامجه الأصلي، ثم افتح الناتج في ورّاق. على Windows يمكن استخدام Microsoft Print to PDF إذا كانت مفعّلة على الجهاز. لا يثبت هذا المشروع طابعة افتراضية جديدة أو إضافة داخل جميع المتصفحات.

قد تمنع بعض البرامج أو الصفحات المحمية أو المستندات المعقدة التحويل، وقد تختلف الخطوط وتخطيطات Excel وفق الجهاز. هذه حدود محرك التحويل والمصدر وليست ضمانًا بأن كل المستندات ستتطابق بصريًا.
