# ورقة · Waraqa

تطبيق سطح مكتب مستقل ومفتوح المصدر لإدارة ملفات PDF على جهازك. واجهة عربية من اليمين إلى اليسار، بلا حساب أو خادم أو رفع للمستندات.

هذا مشروع جديد تمامًا: لا يحتوي على كود Adobe أو Acrobat أو ملفات التفعيل الخاصة بهما. كود التطبيق بترخيص **MIT** ويمكنك تعديله ونشره مع إبقاء إشعار الترخيص. المكتبات التابعة تحتفظ بتراخيصها كما هو موضح في `THIRD_PARTY_NOTICES.md`.

## الوظائف المتاحة في 0.6.0

- عرض الصفحات وتكبيرها وملاءمتها لعرض النافذة، مع صور مصغرة.
- محرر صفحة: تحديد الكلمات أو الفقرات، واستبدالها أو حذفها مع استنتاج الخط والحجم واللون والمحاذاة، وإضافة نصوص عربية وصور، مع معاينة وتراجع وإعادة.
- تحرير مباشر داخل مساحة العمل مع لوحة خصائص يمين الصفحة ومقابض لتحريك العنصر وتغيير حجمه.
- استيراد خطوط TTF/OTF/TTC وحفظها للاستخدام لاحقًا؛ خطوط Windows وOffice المثبتة تظهر تلقائيًا في قائمة الخطوط.
- قوالب جاهزة لتقرير العمل والخطاب الرسمي ومحضر الاجتماع، مع حفظ أي صفحة كقالب `.waraqt` وإدراجها في مستند آخر.
- OCR محلي بالعربية والإنجليزية للمستندات الممسوحة، مع طبقة نص قابلة للبحث والنسخ (يتطلب محرك Tesseract؛ بيانات اللغتين مرفقة).
- بحث داخل المستند، وتحديد النص بالماوس ونسخه.
- مشروعات `.waraq`، وحفظ تلقائي مشفّر محليًا، واستعادة بعد الإغلاق المفاجئ.
- معالجة خلفية مع التقدم والإلغاء، وأدوات مراجعة تشمل التمييز والملاحظات والأسهم والأختام.
- دمج عدة ملفات PDF، أو إضافتها إلى مساحة العمل الحالية.
- نافذة دمج مستقلة لإضافة عدة ملفات وترتيبها قبل بدء الدمج.
- طباعة عبر طابعات Windows، مع معاينة ونطاق صفحات والصفحة الحالية والصفحات المحددة والنسخ التي يدعمها برنامج تشغيل الطابعة.
- إنشاء PDF من صور PNG/JPEG/TIFF/BMP/WebP، بما فيها TIFF متعدد الصفحات.
- تحويل Word وExcel وPowerPoint عند تثبيت Microsoft Office المناسب، أو استخدام LibreOffice للصيغ المدعومة.
- تحويل صفحة ويب أو ملف HTML إلى PDF عبر Chrome أو Edge المثبّت، باستخدام ملف تعريف مؤقت مستقل.
- تحديد متعدد للصفحات، وتغيير ترتيبها بالسحب أو أزرار النقل.
- تدوير الصفحات وحذفها وتكرارها وإضافة صفحة A4 فارغة.
- استخراج صفحات بنطاقات مثل `1-3, 5`؛ يدعم الإدخال بالأرقام العربية أيضًا.
- تقسيم المستند إلى ملفات بعدد صفحات تختاره؛ لا يستبدل ملفات التقسيم الموجودة.
- إضافة طبقة نص بالعربية أو الإنجليزية، أو علامة مائية، وترقيم الصفحات.
- تعديل عنوان المستند واسم المؤلف.
- فتح مستند محمي بكلمة مرور تعرفها، وحماية النسخة الناتجة بكلمة مرور جديدة باستخدام AES-256.
- التراجع والإعادة لآخر 30 خطوة.
- حفظ ذري: يُنشأ الملف الناتج كاملًا قبل استبدال أي ملف تختاره.

## التشغيل على Windows

للتثبيت: شغّل **Waraqa-0.6.0-Setup-x64.exe**. يثبت البرنامج للمستخدم الحالي، ويضيف اختصارات وإلغاء تثبيت ويسجله ضمن «فتح باستخدام» لملفات PDF. لا يستبدل برنامج PDF الافتراضي تلقائيًا؛ يمكنك اختياره بنفسك من إعدادات التطبيقات الافتراضية في Windows.

تتوفر نسخة محمولة أيضًا: فك ضغط **Waraqa-0.6.0-windows-x64.zip** ثم افتح `Waraqa.exe` من داخل المجلد. احتفظ بمجلد `_internal` بجانب الملف التنفيذي؛ لا يحتاج التشغيل إلى تثبيت Python.

النسخة التنفيذية والمُثبّت مبنيان محليًا وغير موقعين بشهادة تجارية. لا يحتاج التثبيت للمستخدم الحالي إلى صلاحيات مسؤول. عرض PDF ودمجه وتنظيمه وطباعته يعمل محليًا. حفظ صفحة ويب يتصل بعنوان الصفحة لتحميل محتواها، ولا يستخدم جلسة تسجيل الدخول أو إضافات المتصفح الشخصية. تحويل Office يحتاج تثبيت البرنامج المناسب؛ لا يثبت ورّاق Office أو LibreOffice أو متصفحًا نيابةً عنك.

## التشغيل من الكود

المتطلبات: Windows 10/11 بنواة 64 بت وPython 3.11 أو أحدث. جرى الاختبار باستخدام Python 3.12 على Windows؛ لم يُختبر إصدار Linux أو macOS.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

يمكن تمرير ملف لفتحه مباشرة:

```powershell
.\.venv\Scripts\python.exe run.py "C:\Documents\example.pdf"
```

لتثبيت أمر `waraq-pdf` أثناء التطوير:

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
```

## الاختبارات والبناء

لبناء المُثبّت ثبّت [NSIS 3.12](https://nsis.sourceforge.io/Download)، وأضف مجلده إلى PATH أو عيّن متغير البيئة `NSIS_COMPILER` إلى المسار الكامل لملف `makensis.exe`.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller WaraqPDF.spec --noconfirm
.\.venv\Scripts\python.exe scripts\build_installer.py
```

أو استخدم `build.ps1` من PowerShell بعد تجهيز Python. الناتج في `dist\WaraqPDF`. يجب توزيع المجلد كاملًا وملفات التراخيص؛ تنسيق المجلد يسمح أيضًا باستبدال مكتبات Qt الديناميكية المتوافقة. مصادر Qt/PySide المطابقة محفوظة بجوار الإصدار داخل `release\dependency-sources` مع روابطها وبصماتها؛ أبقها متاحة مع حزم التشغيل التي تعيد توزيعها. يمكن استعادتها باستخدام `scripts\fetch_qt_sources.py`.

## طريقة الاستخدام

1. افتح ملفًا أو عدة ملفات. يمكن سحب الملفات إلى النافذة أيضًا.
2. اختر صفحة من الجانب. استخدم Ctrl لتحديد صفحات متفرقة أو Shift لنطاق متصل.
3. لتغيير المحتوى اختر «تعديل PDF»، ثم اسحب حول النص أو حدده من القائمة. غيّر النص أو أضف نصًا/صورة، ثم اختر «معاينة التعديل» و«تطبيق على الصفحة» و«إنهاء التعديل». التفاصيل في `docs/EDITING.md`. أداة «نص / علامة مائية» المنفصلة تضيف طبقة فوق المحتوى.
4. اختر «حفظ نسخة». اختر حماية الناتج أو إلغاءها بوضوح، ثم اختر مكان الحفظ. اسم الحفظ الافتراضي يختلف عن اسم المصدر.

الاختصارات: Ctrl+O فتح، Ctrl+Shift+O إضافة ملفات، Ctrl+M نافذة الدمج، Ctrl+Shift+E تعديل محتوى الصفحة، Ctrl+P طباعة، Ctrl+Shift+P معاينة الطباعة، Ctrl+S حفظ نسخة، Ctrl+E استخراج، Ctrl+Z تراجع، Ctrl+Shift+Z إعادة، Ctrl+R تدوير، Ctrl+0 ملاءمة العرض. استخدم أزرار التراجع والإعادة داخل محرر الصفحة لتعديلاته المحلية.

## الحدود الحالية

- ليست هذه النسخة بديلًا كاملًا لجميع وظائف Acrobat: لا يوجد توقيع رقمي معتمد أو تصدير Word. التحرير لا يعيد تنسيق المستند كاملًا كبرنامج Word.
- الاستبدال يحذف العناصر النصية المحددة ويكتب نصًا جديدًا بالخط والحجم اللذين تختارهما. بعض الملفات تقسم الكلمات إلى حروف، وبعضها يضع النص داخل مجموعات غير مدعومة. النص داخل الصور لا يمكن استبداله آليًا. راجع المعاينة وحدد مساحة تكفي النص الجديد.
- حذف العناصر ليس أداة تنقيح أمني أو إزالة بيانات حساسة معتمدة؛ قد يبقى المحتوى داخل بنى أو موارد أو نسخ أخرى في المستند. لا تستخدم المحرر لتنقيح أسرار للنشر.
- يستهدف التطبيق Windows 10/11 بنواة x64. لا يوجد مُثبّت macOS أو Linux، ولا إضافة تُزرع داخل جميع المتصفحات، ولا برنامج تشغيل طابعة افتراضية خاص به.
- ملفات PDF القياسية تتبادل مع البرامج والمتصفحات الداعمة للصيغة؛ هذا لا يضمن كل ملف وكل برنامج. راجع `docs/COMPATIBILITY.md` للاختبارات وحدودها.
- الطباعة ترسم الصفحات بجودة تصل إلى 300 DPI داخل حدود الذاكرة؛ الطابعة وتعريفها يحددان مقاس الورق والنسخ والطباعة المزدوجة. الحفظ العادي لا يحول الصفحات إلى صور.
- تحويل Office يعتمد على محرك خارجي، وقد تختلف الخطوط وتخطيطات الجداول ومناطق طباعة Excel. الملفات التي تتطلب كلمة مرور أو مطالبات تسجيل دخول قد تحتاج فتحها في برنامجها الأصلي أولًا. لا تُشغّل وحدات الماكرو عبر محرك Microsoft Office.
- صفحات الويب التي تحتاج تسجيل الدخول أو حماية أو تفاعل قد لا تتحول كما تراها في جلستك الشخصية. التحويل يستخدم ملف تعريف جديدًا، ولا يتجاوز حواجز تسجيل الدخول أو الشهادات.
- يدعم العارض البحث وتحديد النص ونسخه؛ لا يشغّل JavaScript ولا يدير المرفقات داخل PDF.
- الحفظ يعيد تجميع الصفحات. لا يحافظ على صلاحية التوقيعات الرقمية، ولا ينقل شجرة الإشارات المرجعية أو المرفقات أو خصائص PDF/A كاملة. احتفظ بالأصل عند الحاجة لهذه الخصائص.
- النماذج البسيطة تحتفظ بقيم الحقول في اختبارات الدمج، مع فصل أسماء الحقول بين المستندات؛ لم تُختبر جميع أنواع XFA أو النماذج المعقدة.
- الحماية في المصدر لا تنتقل تلقائيًا إلى الناتج. يُفعّل اختيار الحماية افتراضيًا عند التصدير من مدخل مشفّر، ويلزم تحديد كلمة مرور للنسخة الجديدة.
- يُقرأ المستند في الذاكرة وقد تحتاج الملفات الكبيرة ذاكرة إضافية. التجهيز والبحث وOCR تعمل في عمليات خلفية قابلة للإلغاء؛ نافذة الطباعة والرسم إلى تعريف الطابعة يظلان ضمن واجهة Windows.
- النصوص المضافة تستخدم الخط المتاح على جهازك. تُشكّل العربية عبر Qt وتُضمّن الخطوط المستخدمة داخل طبقة PDF التي ينشئها Qt.
- كلمة مرور المدخل تبقى في ذاكرة العملية لتتمكن من إعادة التجميع؛ لا يحفظها التطبيق في ملف إعدادات أو سجل خاص به.

## بنية المشروع

- `waraq/core.py`: نموذج المستند، المراجع غير المتلفة للصفحات، التاريخ، الدمج والتشفير والحفظ.
- `waraq/rendering.py`: معاينة PDFium وطبقات النص المتجهية باستخدام Qt.
- `waraq/editing.py` و`waraq/editor_dialog.py`: تعديل عناصر الصفحة وتحديدها ومعاينتها والتراجع عنها.
- `waraq/app.py`: واجهة سطح المكتب العربية.
- `waraq/printing.py`: اختيار الصفحات والرسم على طابعات Windows ومعاينة الطباعة.
- `waraq/conversion.py`: تحويل الصور وOffice وHTML والويب مع كشف المحركات المتاحة.
- `installer/`: مصدر مُثبّت NSIS وتسجيل «فتح باستخدام» وإلغاء التثبيت.
- `tests/`: اختبارات بنية PDF والتشفير والنماذج والنص العربي.
- `scripts/`: بناء العينات وحزم الإصدار وتجميع إشعارات المكتبات.
- `docs/`: ملاحظات الاختبار والتصميم.

لا يحتاج التطبيق إلى حساب أو خدمة تفعيل. حفظ الويب هو الوظيفة التي تطلب اتصالًا بالصفحة، وقد تتصل برامج Office/المتصفح الخارجية بخدماتها وفق إعداداتها.
